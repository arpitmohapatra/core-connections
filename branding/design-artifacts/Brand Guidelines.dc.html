Brand guidelines Core Connections Ottawa Pessary Clinic
Brand guidelines v1.0 · final · two sibling clinics

Two marks, one family.

Both logos are built from circles and share one typeface, Urbanist: rings that connect for Core Connections, a coral ring resting on a sage arc for the Ottawa Pessary Clinic. Wordmarks are outlined vector paths, and each subtitle is tracked so its ink width matches the name above it exactly. Every file below is an SVG in assets/brand/.

Core Connections Physiotherapy

Mark: approved · Wordmark: Urbanist

Construction and alignment

  1. x = the core's diameterOne third of the mark's height. Keep at least x clear on every side.
  2. Flush left, flush rightPHYSIOTHERAPY is tracked to 0.3 em so its ink runs edge to edge with "core connections".
  3. Centred on the text blockThe mark is 1.32× the text block height and shares its vertical centre. Gap to text is 0.26× mark height.
  4. Lowercase over capsUrbanist ExtraBold lowercase at −2% tracking over SemiBold caps. The round bowls echo the rings.

Versions and minimum size

One colour · fax, stamps, embroidery
Reverse · on Night or photography overlays
Minimum · lockup 140 px wide, mark 20 px. Below that, use the mark alone.

Pattern · Connected rings

The mark's three rings, repeated on a triangular grid. Lime dots fall where the cores would be. Use behind hero panels, cards' empty states and print backs, never behind body text.

Motion · Converge

0–1.6 s · rings rotate 120° into place, staggered 120 ms 0.95 s · core pops in with a soft overshoot 1.25 s · wordmark slides in, subtitle 200 ms later Idle · core pulses 8% every 4 s. Reduced motion shows the final frame.

Ottawa Pessary Clinic

Mark: Supporting Arc · Wordmark: Urbanist

Construction and alignment

  1. x = one third of the markSame rule as Core Connections, so the two logos sit at equal weight side by side.
  2. Same type as Core Connections"ottawa" in Urbanist ExtraBold lowercase over SemiBold caps, so the two clinics read as one family.
  3. Matched measureThe descriptor is tracked to 0.2 em and sized so both lines end on the same vertical.
  4. Centred on the text blockMark is 1.42× the text block height with a 0.24× gap.
