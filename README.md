# Core Connections Physiotherapy

A dependency-free, static website for Core Connections Physiotherapy.

## Local preview

Open `index.html` directly in a browser, or run `python3 -m http.server` in this folder and visit `http://localhost:8000`.

## GitHub Pages

The included GitHub Actions workflow deploys the website whenever `main` is updated. In the GitHub repository, enable **Settings → Pages → Build and deployment → GitHub Actions**.

`CNAME` is set to `core-connections.ca`; keep it only after the domain DNS is pointed to GitHub Pages.
